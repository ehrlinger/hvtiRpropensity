# Assert that a column contains valid probabilities (0 \<= x \<= 1)

Assert that a column contains valid probabilities (0 \<= x \<= 1)

## Usage

``` r
.check_probability(data, col, hint = NULL)
```

## Arguments

- data:

  A data frame.

- col:

  Name of the column to check.

- hint:

  Optional sentence appended to the range error.

## Value

Invisible NULL.
