# Level pairs for a multi-level balance table

Level pairs for a multi-level balance table

## Usage

``` r
.smd_level_pairs(levels, scheme)
```

## Arguments

- levels:

  Treatment levels, reference first.

- scheme:

  Any of `"reference"`, `"adjacent"`, `"all"`.

## Value

A data frame of unique pairs with columns `level` and `versus`.
