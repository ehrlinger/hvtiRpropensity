# Validate a declared outcome-level contract

Validate a declared outcome-level contract

## Usage

``` r
.check_outcome_levels(data, outcome_col, outcome_levels, imputation_col = NULL)
```

## Arguments

- data:

  Model data.

- outcome_col:

  Outcome column.

- outcome_levels:

  Complete declared levels as character strings.

- imputation_col:

  Imputation column, or `NULL`.

## Value

Invisible `NULL`.
