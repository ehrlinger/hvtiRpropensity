# Validate coefficient and covariance inputs for one imputation

Validate coefficient and covariance inputs for one imputation

## Usage

``` r
.check_inference_input(estimate, covariance, terms, imputation)
```

## Arguments

- estimate:

  Named numeric coefficient vector.

- covariance:

  Named covariance matrix.

- terms:

  Reference term order.

- imputation:

  Imputation label used in errors.

## Value

Invisible `NULL`.
