# Build a final inference table

Build a final inference table

## Usage

``` r
.inference_table(terms, estimate, covariance, df, conf_level, pooled)
```

## Arguments

- terms:

  Parameter names.

- estimate:

  Parameter estimates.

- covariance:

  Final covariance matrix.

- df:

  Per-parameter degrees of freedom.

- conf_level:

  Confidence level.

- pooled:

  Whether estimates were pooled.

## Value

A data frame.
